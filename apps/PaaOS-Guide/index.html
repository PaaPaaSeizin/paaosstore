▶ 1. 基本操作とシステムUI

🔒 ロック画面

  • スライダー を右にドラッグするか、スペースキー を押すと解除。
  • パスコードを設定している場合は、4桁の数字を入力（キーボード対応）。
  • 壁紙はロック画面とデスクトップで共有されます。

📱 ホーム画面（デスクトップ）

  • アプリアイコンをタップで起動。
  • 「編集」ボタン（右下）でアイコンを移動・削除（編集モードではアイコンが揺れます）。
  • 「アプリ一覧」（左下）で全アプリを表示し、ホームに追加/削除できます。

📊 ステータスバー（上部）

  • 時刻表示、PaaOSのバージョン表記。
  • ルート権限を取得すると # が表示されます。
  • タップすると クイックパネル が開きます。

⚡ クイックパネル

  • テーマ切替、再読込、設定・通知・アプリ一覧起動、スクリーンショット、フルスクリーン切替。
  • 各アイコンは丸形で、タップで実行。

🏠 ホームバー（下部の白いバー）

  • タップ でホームに戻る（アプリを閉じる）。
  • 上にスワイプ（80px以上） でアプリスイッチャーを開く。
  • マウスでも同様にドラッグ操作可能。
💡 ヒント: フルスクリーンモードではデバイスの枠が消え、ブラウザ全画面で表示されます。

▶ 2. 標準アプリケーション

📁 ファイルマネージャー

  • ホーム画面: 画像・動画・音楽・ドキュメント・ゴミ箱・すべて（ブラウザ）に分類。
  • ブラウザモード: フォルダ階層を表示。新規作成、名前変更、削除（ゴミ箱へ）、検索、コピー/切り取り/貼り付け、複数選択一括操作。
  • プレビュー: テキスト（編集可能）、画像、動画、音楽、ZIPアーカイブ（内部ファイルの抽出）。
  • ゴミ箱: 削除したファイルを復元または完全削除。

⚙️ 設定アプリ

  • 一般: ユーザー名、ドックアプリの変更、バックアップ/復元、GitHubからのシステムファイルダウンロード。
  • 画面: テーマ（ダーク/ライト）、フォント（デフォルト/Noto Sans JP）、絵文字（デフォルト/Noto Color Emoji）、アクセントカラー（プリセット/HSLカスタム/壁紙から抽出）、Fluid Glow Design（ガラス効果レベル）、カスタムCSSテーマのアップロード。
  • モジュール: .modpaa ファイルのインストール、有効/無効切り替え、優先度変更、削除。
  • セキュリティ: ロック画面用4桁パスコードの設定/解除。
  • 情報: ストレージ使用量、工場出荷リセット、システム情報（info.txt）。
  • アップデート: オンラインアップデート、手動ZIPアップデート。
  • 再起動: OS再起動（ロック画面へ戻る）。
  • 開発者向けオプション: レイアウト境界線、タップ座標、パフォーマンスモニター、メモリ詳細、キャッシュクリア、UI再描画、壁紙再読込、デバイス情報、エラーログ表示、言語設定（ベータ）。

📺 YouTube アプリ

  • APIキーとOAuth Client IDを設定することで、検索・再生・コメント表示・チャンネル情報が利用可能。
  • タブ: ホーム（トレンド）、ショート（縦型短尺）、アカウント（指定チャンネル/ログインユーザーの動画）、履歴（検索履歴）。
  • 埋め込みモード: URLまたは動画IDを直接入力して再生。
  • OAuthログイン: Googleアカウントでログインすると自分のチャンネル情報を表示。

>_ コマンドプロンプト

  • 200以上のコマンドを搭載（help で一覧表示）。
  • ファイル操作、システム操作、設定変更、ユーティリティ、危険操作（ルート権限が必要なものも）。
  • タイポ補完（類似コマンド提案）、履歴（上下矢印キー）、エイリアス、外部コマンド登録（cmdadd）。
  • ルート権限（root）でシステム内部への完全アクセスが可能。

🔔 通知センター

  • システムやアプリからの通知を一覧表示。個別削除・全削除可能。
  • 保存先: system/notification.json

🛒 アプリストア

  • ストアデータベースからアプリ一覧を取得。
  • インストール/アップデート/アンインストールが可能。
  • インストールしたアプリは apps/<appId>/ に展開され、ホーム画面に自動追加。

▶ 3. マルチタスク機能

🔄 アプリスイッチャー

  • ホームバーを上にスワイプ（またはドラッグ）すると開く。
  • 起動中のアプリがカード表示され、左右にスクロール可能。
  • カードを 上にフリック するとそのアプリを終了（kill）。
  • カードをタップするとそのアプリを前面に復帰。
  • 下部に「分割表示」と「ポップアップ」ボタンあり。

⊞ 分割表示（スプリットスクリーン）

  • スイッチャー内の「分割表示」ボタンで2つのアプリを選択。
  • 上下に分割され、分割線をドラッグ してサイズ変更可能。
  • 分割線をタップするとメニューが開き、「上下入れ替え」「アプリ変更」「終了」ができます。
  • 分割中はドックが隠れます。

⤴ ポップアップウィンドウ

  • スイッチャー内の「ポップアップ」ボタンでアプリを選択し、フローティングウィンドウとして開く。
  • ヘッダーをドラッグして移動、右下のハンドルをドラッグしてリサイズ。
  • ヘッダーの「─」で最小化（ドック表示）、「✕」で閉じる。
💡 ヒント: ポップアップ中はドックが隠れますが、最小化すると再表示されます。

▶ 4. システム設定・カスタマイズ

🎨 テーマとアクセントカラー

  • ダーク/ライト: 設定アプリの「画面」から切り替え。
  • アクセントカラー: プリセットまたはHSLスライダーで自由に設定。壁紙から自動抽出も可能。
  • カスタムテーマ: CSSファイル（.css）をアップロードして任意のスタイルを上書き（例: :root { --win-bg: #1a1a1a; }）。

🔤 フォントと絵文字

  • フォント: デフォルト（システム標準）または Noto Sans JP。
  • 絵文字: デフォルト（OS依存）または Noto Color Emoji（試験的）。

✨ Fluid Glow Design

  • 半透明パネル（クイックパネル、ドック、モーダルなど）に、ぼかし＋歪み＋光沢のガラス効果を追加。
  • 設定の「画面」で「オフ」または「オン」を選択（パフォーマンスに影響するため、低スペック端末ではオフ推奨）。

🖼️ 壁紙

  • 設定アプリの「画面」またはコマンドプロンプト（wallpaper）から画像またはHTMLファイルを選択。
  • 保存先: system/wallpaper.{png,html,...}

🌐 言語設定（ベータ）

  • 翻訳ファイル（.txt）をアップロードし、UIのテキストを切り替え可能。
  • ファイル形式: 原文=翻訳 の行を列挙。

▶ 5. ファイルシステムとデータ管理

📂 ディレクトリ構造

  • ルート: ユーザーが初回起動時に選択したフォルダ。
  • 標準フォルダ: apps/, pictures/, videos/, music/, documents/, system/, trash/, backup/。
  • システムフォルダ (system/):
    • config.json – 全設定
    • notification.json – 通知履歴
    • errorlog.json – エラーログ
    • version.txt – OSバージョン
    • info.txt – システム情報（OS名、ビルド番号など）
    • boot/ – 起動アニメーション画像
    • shutdown/ – シャットダウンアニメーション画像
    • language/ – 翻訳ファイル
    • themes/ – カスタムCSSテーマ
    • modules/ – インストール済みモジュール（.modpaa）

🗑️ ゴミ箱

  • 削除したファイルは trash/ に移動され、元のパス情報は system/trash_meta.json で管理。
  • ゴミ箱から復元または完全削除が可能。

📦 バックアップと復元

  • バックアップ: 全ユーザーデータ（backup/ を除く）を ZIP 圧縮し、backup/backup_タイムスタンプ.paabak として保存（100MB超のファイルはスキップ、進捗表示とキャンセル対応）。
  • 復元: .paabak を選択し、「上書き（全データ置換）」または「新規フォルダに展開」を選択可能。
⚠️ 注意: バックアップ・復元において大容量ファイルはスキップされることがあります。

▶ 6. 高度な機能（ルート権限・モジュール・リカバリー）

🔑 ルート権限 危険

  • コマンドプロンプトで root を実行し、確認ダイアログで承諾すると取得。
  • ルート権限があると、js（JavaScript実行）、cmdadd（独自コマンド登録）、SYSTEM_WRITE_FORCE などの危険な操作が可能。
  • ステータスバーに # が表示され、ルート状態が視覚化されます。

🧩 モジュールシステム

  • .modpaa（ZIP形式）で、manifest.json と module.js を含む。
  • 設定アプリの「モジュール」からインストール・有効化・無効化・優先度変更・削除が可能。
  • モジュールは サンドボックス化されたAPI を受け取り、ログ出力、通知表示、スタイル追加/削除、設定の読み書き、postMessage 通信などができる。
  • 優先度が高いほど後から読み込まれ、他のモジュールの動作を上書き可能。

🔄 アップデート機構

  • オンライン: UPINFO.json をGitHubから取得し、新しいバージョンがあれば UP_*.zip をダウンロードして os.html を更新。
  • 手動: 任意のZIP（os.html を含む）を選択して更新。
  • 更新後は新しい {rand}os.html にリダイレクトされ、古いファイルは削除されます。

💀 ブルースクリーン（BSOD）とリカバリーモード

  • BSOD: システムエラー時、またはコマンド bsod 実行時に表示。エラーコードと関与ファイルを表示し、10秒後にリカバリーモードへ移行。
  • リカバリーモード: 起動中（再起動アニメーション中）に画面下部をタップするか、BSOD後に自動移行。
  • メニュー: 「続行（再起動）」「ユーザー設定初期化」「更新ファイルインストール」「システム再読み込み」。
⚠️ 注意: ルート権限やモジュールは信頼できるものだけを使用してください。システムに損害を与える可能性があります。

▶ 7. 開発者向け情報（内部構造・API）

🧠 カーネルオブジェクト (kernel)

  • 全機能は PaaOS_Kernel クラスのインスタンス kernel に実装。
  • 主要メソッド: launch(id), goHome(), killApp(id), reboot(), showDialog() など。
  • デバッグ用: window.paaosStats() でシステム統計情報をコンソールに出力。

📡 メッセージ通信（postMessage）

  • アプリ（iframe内）とカーネルは window.parent.postMessage で通信。
  • 対応アクション: launchApp, goHome, SHOW_DIALOG, CALL_FILE_PICKER, GET_SYSTEM_STATS, INSTALL_MODULE など多数。
  • 応答は type フィールドで識別され、requestId でリクエストと対応。
  • セキュリティ: システムアプリ以外からの危険アクション（BSOD, REBOOTなど）はブロックされ、レートリミット（1秒あたり50メッセージ）が適用されます。

🗂️ ファイルシステムAPI

  • File System Access API を使用し、ローカルフォルダをルートとして読み書き。
  • ディレクトリハンドルは IndexedDB に保存され、再起動後も同じフォルダを参照。

📊 システム統計API

  • GET_SYSTEM_STATS: 稼働時間、メモリ使用量、アプリ起動回数、アクティブ時間など。
  • GET_STORAGE_STATS: ストレージ使用量/上限。

🔌 モジュールAPI（開発者向け）

  • モジュールは kernel と api オブジェクトを受け取る。
  • api.log(), api.notify(), api.addStyle(), api.getConfig(), api.send() など。
  • init() と cleanup() フックを実装可能。
💡 ヒント: 開発者は kernel オブジェクトを直接操作することで、システムのあらゆる部分を制御できます。ただし、権限のないアプリからの操作は制限されます。

▶ 8. ショートカット＆ジェスチャー

  • スペースキー（ロック画面） – ロック解除
  • ホームバー上スワイプ – スイッチャー表示
  • ホームバータップ – ホームに戻る
  • ステータスバータップ – クイックパネル開閉
  • アイコン長押し（編集モード） – アイコン移動
  • ポップアップヘッダードラッグ – ウィンドウ移動
  • ポップアップ右下ドラッグ – リサイズ
  • 分割線ドラッグ – 分割比率変更
  • スイッチャーカード上フリック – アプリ終了
  • Ctrl+R（ブラウザ） – OS再起動（ページ再読込）
